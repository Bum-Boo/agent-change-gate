# Agent Change Gate 0.2.0

This is the first public alpha for manual installation. It is not yet listed in Obsidian Community Plugins.

## Highlights

- Choose the current note body, an exact selection, or existing YAML frontmatter as the outbound scope.
- Keep agent output as a draft until a bounded, complete diff is reviewed and explicitly approved.
- Refuse stale edits when the note path or captured content changes while an agent is responding.
- Use first-class Hermes discovery on Windows/WSL or configure another argv-only ACP stdio agent.
- Keep scope receipts without instruction, note-body, or model-response plaintext.
- Bound transport frames, responses, history, checkpoints, audit retention, and diff work.

## Install

1. Download `agent-change-gate-0.2.0.zip` from the assets below.
2. Extract the complete archive into `<vault>/.obsidian/plugins/agent-change-gate/`.
3. Reload Obsidian Community plugins and enable **Agent Change Gate**.
4. Open the plugin settings and run **Detect and check agents**.

The archive includes project and bundled-dependency license notices. `SHA256SUMS.txt` verifies the archive and individual release assets.

## Known limits

- No end-to-end model Ask/Edit/Apply test has been claimed yet.
- No manual Obsidian GUI matrix or external beta has been completed.
- No second ACP implementation has been verified.
- The plugin constrains what its host sends and writes; it does not sandbox the separate ACP process.
- Funding is not enabled, and this release is not an Obsidian Community Plugins listing.

Report sensitive security issues through [GitHub private vulnerability reporting](https://github.com/Bum-Boo/agent-change-gate/security/advisories/new), never through a public issue.
