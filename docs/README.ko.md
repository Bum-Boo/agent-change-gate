# Agent Change Gate 빠른 안내

> Hermes와 호환 ACP 에이전트가 이 채팅으로 돌려준 편집안을 범위 검사하고, 사용자가 검토하기 전까지 초안으로 유지하는 Obsidian 데스크톱 플러그인입니다.

현재 버전은 `0.2.0` 로컬 알파입니다. 핵심 경계와 저장·전송 제한은 자동 테스트를 거쳤고 Hermes Agent 0.20.0의 ACP 초기화도 확인했지만, 실제 모델 대화와 외부 베타 사용성은 아직 검증되지 않았습니다.

## Hermes로 시작하기

1. Hermes Agent와 사용할 프로필을 먼저 설치·설정합니다.
2. Obsidian 1.13.4 이상에서 Agent Change Gate를 활성화합니다.
3. 플러그인 설정에서 **Detect and check agents**를 실행합니다. 플러그인은 이 검사에서 모델 프롬프트를 보내지 않지만, 에이전트 실행 파일 자체의 시작 동작은 통제하지 못합니다.
4. Markdown 노트를 열고 오른쪽 사이드바에서 Agent Change Gate를 엽니다.
5. 에이전트, 질문/편집 작업, 노트 범위를 고른 뒤 요청을 보냅니다.
6. 편집안은 추가·삭제 줄을 확인한 다음 직접 적용하거나 버립니다.

Windows에서는 WSL Hermes를 먼저 자동 탐색하며 기본 실행 형식은 다음과 같습니다.

```text
hermes -p <profile-id> acp
```

## 대화 문맥

기본값인 **Context: scope only**는 이번 지시문과 선택한 현재 범위만 보냅니다. **Context: exact-scope thread**를 직접 선택하면 같은 에이전트·노트·범위 정체성(종류, 위치, 내용 해시)에 연결된 최근 사용자/어시스턴트 메시지를 최대 12개 추가로 보냅니다. 이 이전 메시지에는 과거 지시문이나 해당 범위를 인용한 답변이 들어 있을 수 있습니다.

## 다른 ACP 에이전트 연결

설정에서 실행 파일, 한 줄당 하나의 인수, 절대 작업 경로, native/WSL 전송 방식을 직접 등록할 수 있습니다. 셸 명령문과 사용자 지정 환경 변수 입력란은 제공하지 않습니다. 실행 인수는 `data.json`에 평문 저장되므로 토큰, API 키, 비밀번호를 넣지 마세요. 자격 증명은 해당 에이전트의 자체 보안 설정에서 관리해야 합니다.

다른 ACP 구현과의 호환성을 자동 보장하지 않습니다. 검증된 정확한 버전은 [ACP compatibility](COMPATIBILITY.md)를 확인하세요.

## 게이트가 보장하는 범위

- 플러그인이 현재 노트에서 읽어 호스트 프롬프트에 넣는 본문은 사용자가 고른 본문·선택 영역·YAML frontmatter뿐입니다.
- 기본 설정에서는 이전 대화를 보내지 않으며, 정확한 범위 문맥은 사용자가 명시적으로 켜야 합니다.
- ACP 클라이언트는 파일시스템·터미널 capability를 제공하지 않고 권한 요청을 거절합니다.
- 플러그인이 적용하는 모든 편집은 diff 검토와 명시적 승인이 필요합니다.
- 일반 크기 비교는 정확한 줄 diff를 사용합니다. 비교 작업 한도를 넘으면 전체 내용을 빠뜨리지 않는 거친 삭제/추가 diff로 전환하고, 안전하게 전부 표시할 수 없으면 적용 버튼을 비활성화합니다.
- 캡처 뒤 노트 경로나 내용이 달라진 오래된 응답은 적용하지 않습니다.
- bidi 제어 문자는 차단하고, 보이지 않는 유니코드·탭·후행 공백은 diff에 표식으로 드러냅니다.
- 요청 영수증에는 에이전트 프로필 ID와 실행 지문, vault 상대 노트 경로, 작업·범위, 범위와 선택 문맥의 글자 수·SHA-256 해시, 시각과 결과를 저장하지만 지시문·노트·답변 원문은 저장하지 않습니다. 해시는 익명화가 아닌 결정적 지문이므로, 짧거나 예상 가능한 원문은 추측 대조가 가능합니다.

**Stop**은 플러그인이 응답을 기다리는 일을 즉시 멈추고 ACP 취소를 요청합니다. 에이전트 프로세스가 취소를 무시할 수는 있지만, 그 요청에서 돌아온 편집안은 적용하지 않습니다.

## 로컬 저장

대화는 에이전트 실행 정체성과 vault 상대 노트 경로별로 나뉩니다. 전체 200개 thread, 메시지 본문 200만 자, 180일을 상한으로 자동 정리됩니다. 적용한 편집의 복구 스냅샷은 최대 20개·총 300만 자·30일이며, 한 스냅샷의 전체 노트 전후 사본 합계는 60만 자와 4,000줄을 넘을 수 없습니다. 선택 영역만 보냈더라도 복구 스냅샷은 자격이 되는 편집의 전체 노트 전후 사본을 담습니다. 큰 노트는 검토 후 적용할 수 있어도 플러그인 자체 복구 스냅샷을 만들지 않습니다.

`data.json`의 대화·설정·스냅샷은 암호화되지 않은 평문입니다. vault 설정에 따라 Obsidian Sync, OneDrive, Dropbox 또는 백업 도구가 이 파일을 다른 기기나 외부 저장소로 복사할 수 있습니다.

## 보장하지 않는 것

Hermes와 다른 ACP 에이전트는 별도 로컬 프로세스입니다. Agent Change Gate는 그 프로세스를 OS 수준에서 샌드박스하지 않습니다. 에이전트는 자체 도구, 네트워크, 모델 제공자, 자격 증명, 메모리와 운영체제 권한을 가질 수 있습니다. MCP 억제 플래그, 빈 세션 MCP 목록, 작업 경로, 취소 요청 역시 악성 프로세스가 반드시 지킨다는 보장은 없습니다.

민감한 vault에서는 신뢰하는 에이전트와 모델 제공자를 사용하고, 실제 프로세스 경계가 필요하면 별도 OS 계정·VM·컨테이너를 사용하세요. 자세한 내용은 [PRIVACY.md](../PRIVACY.md)와 [SECURITY.md](../SECURITY.md)를 확인하세요.
